# Бизнес Пульс

Прототип веб-сервиса для собственников офлайн-бизнеса: ключевые показатели компании на одном экране.

## Демо

Статический сайт без сервера и внешних API. Для демонстрации используются синтетические данные трёх компаний (клиника, магазин, кофейня). Есть просмотр KPI и импорт CSV с сопоставлением столбцов. Вся обработка CSV выполняется локально в браузере; данные после закрытия страницы не сохраняются.

## Публикация через GitHub Pages

1. Загрузите `index.html`, `README.md`, `.nojekyll` в корень ветки `main`.
2. В GitHub откройте **Settings → Pages**.
3. В разделе **Build and deployment** выберите **Deploy from a branch** и ветку **main**, папку **/(root)**. Нажмите Save.
4. Адрес сайта будет иметь вид `https://<имя-пользователя>.github.io/<имя-репозитория>/` после успешной публикации.

## Ограничения

- Это демонстрационный прототип, не готовый финансовый SaaS.
- Импортирует **CSV**, но пока не XLSX.
- Показатели демонстрационных компаний синтетические.
- Не загружайте в публичный прототип сведения о пациентах и другие конфиденциальные данные без соответствующих оснований и проверок.
- Сайт не использует backend, авторизацию и постоянное хранение данных.
