# Бизнес Пульс — Telegram bot (демо)

Этот отдельный Node.js-процесс подключает опубликованный сайт **Бизнес Пульс** к Telegram. Он не использует код или токены CityAI.

## Что уже работает

- `/start` — приветствие с кнопкой открытия Telegram Mini App.
- Кнопка меню бота **Бизнес Пульс** открывает веб-приложение.
- `/report` — ссылка на демонстрационный обзор.
- `/subscribe`, `/unsubscribe`, `/status`, `/test` — управление тестовыми утренними уведомлениями.
- Сообщения раз в день по московскому времени (по умолчанию 09:00) только после явной подписки.
- Идентификаторы подписанных Telegram-чатов хранятся локально на сервере, а не в GitHub Pages.

**Это ещё не передача реальных KPI в Telegram.** CSV сейчас обрабатывается только в браузере и после закрытия не сохраняется. Бот не имеет доступа к этому файлу. До появления защищённого backend/хранилища его утреннее сообщение является тестовым напоминанием об открытии демо и честно об этом сообщает.

## Как запустить

1. Бот уже создан: [@business_pulse_app_bot](https://t.me/business_pulse_app_bot). Если меняете его username, обновите `BP_BOT_USERNAME` в `.env`.
2. На VPS установить Node.js версии **20.6+** (или использовать установленную подходящую версию).
3. Скачать репозиторий в отдельную папку (не в папку CityAI): `git clone https://github.com/Balakhmatov/business-pulse.git`.
4. Перейти в директорию `business-pulse/bot` и создать локальный `.env` из `.env.example`.
5. Записать в `.env` токен от BotFather, сохранить `BP_BOT_USERNAME=business_pulse_app_bot`. Токен **никогда не отправлять в чат и не коммитить**.
6. Запустить: `node --env-file=.env index.mjs` (запускать из директории `bot`).
7. В Telegram открыть бота, отправить `/start`, затем `/test` и `/subscribe`.

Процесс должен постоянно работать для приёма команд и доставки сообщений. После тестирования добавим отдельный systemd-сервис или контейнер. HTTPS-домен webhook для этого демо **не нужен**, используется long polling Telegram Bot API. Нельзя запускать два экземпляра с одним и тем же токеном одновременно.

### Настройки

- `BP_BOT_USERNAME` — username конкретного бота. Код проверяет имя через `getMe` до изменения команд и меню, чтобы не затронуть чужого бота.
- `BP_APP_URL` — HTTPS-адрес Pages.
- `BP_TIMEZONE` — часовой пояс доставки по умолчанию (`Europe/Moscow`).
- `BP_SEND_HOUR` — час доставки от 0 до 23 (по умолчанию 9).
- `BP_SUBSCRIBERS_FILE` — приватный JSON-файл подписок, не помещать в каталог публичного сайта.

### Дальше

Для настоящих персональных цифр понадобятся серверное хранилище, аутентификация пользователя/компании через проверку подписанных данных Telegram initData, безопасная загрузка файлов/подключение источника и расчёт метрик на сервере. Нельзя считать отображаемый в браузере Telegram user ID подтверждённой личностью. Нельзя пересылать загруженный CSV произвольному подписчику без привязки и проверки доступа.
